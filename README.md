## Description

This project implements **Principal Component Analysis (PCA)** on a dataset containing the grades of six students in four subjects:

- Mathematics
- Statistics
- Programming
- Algorithms

The objective is to understand how PCA works and compare a **PCA implementation from scratch** with the implementation provided by **Scikit-learn**.

## Contents

The notebook `TP2_Solution.ipynb` contains:

- Dataset loading and exploration
- Data standardization
- Covariance matrix calculation
- Eigenvalues and eigenvectors computation
- PCA implementation from scratch
- PCA using Scikit-learn
- Explained and cumulative variance
- Comparison of both implementations
- PCA visualizations
- Interpretation of the results

## Technologies

- Python 3.12
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook
